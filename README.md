# Proyecto de Machine Learning: Análisis de Discriminación y Seguridad Ciudadana (EH2025)

## 📌 Descripción del Proyecto
Este proyecto aplica técnicas de Ciencia de Datos y Machine Learning sobre la Encuesta de Hogares (EH2025) de Bolivia para analizar la relación entre la victimización por hechos delictivos y la percepción de discriminación social.

**Caso Elegido:** Caso 3 - Análisis de la Discriminación y la Seguridad Ciudadana.
